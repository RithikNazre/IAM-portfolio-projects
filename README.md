## Projects

### 1. End-to-End JML Workflow in Okta
A complete Joiner-Mover-Leaver access lifecycle simulation:
- Onboarded a test employee with group-based access provisioning
- Simulated a department transfer (Sales → Marketing), showing
  automatic access changes tied to group membership
- Offboarded the employee using a single deactivation action,
  revoking all app access and active sessions at once
